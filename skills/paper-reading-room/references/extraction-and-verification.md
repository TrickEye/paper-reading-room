# 提取与验收工具

## 下载及清点

使用可用的网页／网络工具读取用户给定的论文页，从官方来源解析 PDF、HTML、补充材料和版本。确认下载文件的 PDF 文件头并用解析器打开，记录标题、作者、标识符、版本、页数、最终 URL、获取日期和文件摘要。登录页、HTML 报错页或下载失败不能当作 PDF。没有成功取得原文时，先说明缺什么，不从摘要或记忆扩写全文。

生成内容清单时，逐页检查章节及浮动元素。正文和附录的图表可能连续编号，也可能分开编号；算法框、长表、提示词图及多面板图不能简单按 PDF 图片对象数量统计。

## 提取原图

优先顺序：

1. 同版官方 HTML 或作者源文件的原始资源（SVG、PNG、JPEG 等），确认与 PDF 对应。
2. 直接提取 PDF 内嵌图像；多面板／组合图若由多个对象组成，不能只取一个对象。
3. 原图为 PDF 原生矢量、表格式对话框或提示词框时，保留独立矢量资源，或精确裁出其区域后以足够清晰的分辨率渲染。图注与正文不一起截图。

`extract_figures.py` 执行第 2、3 种提取，不负责猜测边界。先用 PDF 渲染图和位置数据确定映射，再写计划，例如：

```json
[
  {"figure": 1, "page": 1, "image_index": 0},
  {"figure": 8, "page": 18, "bbox": [80, 70, 515, 423]}
]
```

以上为已核实的 SkillForge 示例坐标，**不适用于其他论文**。`page` 为 1 起始的 PDF 页序号；`image_index` 是 pypdf 该页图片列表的 0 起始索引；`bbox` 是相对于未旋转页面左上角的 `[x0, y0, x1, y1]`，单位为 PDF point，1 point = 1/72 英寸。不要直接传入以像素或 PDF 左下角为原点的坐标。脚本拒绝未处理的旋转页和整页渲染。

```bash
python3 skills/paper-reading-room/scripts/extract_figures.py 'paper.pdf' \
  --plan '/tmp/figure-plan.json' --out '/tmp/paper-figures' \
  --source-url '已核实的原始PDF地址'
```

依赖：`pypdf`、用于图像尺寸的 Pillow；矢量渲染另需 PATH 中有 `pdftoppm`。优先使用已提供的工作区运行时。输出目录必须为空，以免覆盖已审核资源。先在临时目录完成提取和检查，再把图像复制到该论文源目录的 `assets/`，将 `assets.json` 放在源目录顶层。清单保存源 PDF 摘要、源页、提取方式、资源名／边界、图像尺寸及文件摘要。

逐一打开输出图像，同时对照原页，确认没有：

- 周围正文、页码或另一张图；
- 缺失的子图、标题、图例、轴标签、箭头或底边；
- 把单个 PDF 图片对象误认为完整图；
- 因低分辨率、错误边界或透明背景而不可读的文字。

不要以图像尺寸或长宽比自动证明“不是整页截图”；某些提示词原图本来就很长。正确的图像来源记录和视觉对照不可省略。

## 自动审计

```bash
python3 skills/paper-reading-room/scripts/audit_reading_page.py 'public/papers/skillforge.html' \
  --source-dir data/skillforge --index public/index.html
```

该脚本只读取输入，使用 Python 标准库。检查：

- ID、单元 ID 唯一；非共享公式单元都有一个非空中文及英文直接子元素；
- 不再使用旧 `.original-page` 整页图容器或 `.source-page` 按页折叠原文；
- 内部锚点、阅读页及索引本地链接存在；
- 图像资源非空、base64 可解析、alt 和尺寸存在，无依赖远程资源的图片／脚本／样式；
- 有源清单时，图号数量、发布图片与源文件字节及摘要一致；
- 有表格 JSON 时，将 HTML 表格的合并单元格展开，与全部源数据行比较；
- 参考文献数量及双语源字段基本完整。

新论文若没有约定的源数据目录，可先用经原作清点的数量检查结构：

```bash
python3 skills/paper-reading-room/scripts/audit_reading_page.py 'public/papers/new-paper.html' \
  --expected-figures 6 --expected-tables 3 --index public/index.html
```

此处 6、3 仅为命令示例，必须替换为该论文实际数量。脚本默认按 ACE 的 `.ltx_figure`、`.ltx_bibitem`、`F图号`、`T表号` 和双语结构检查。采用其他 DOM 或源数据 schema 时应适配检查器，不能为了得到 PASS 而删除检查或随意改变原文结构。

`tables.json` 预期 `[{"number":1,"rows":[["方法A","0.600"]]}]`；文本单元格可用 `["中文", "English"]`。脚本兼容当前 SkillForge 遗留浮点数的三位小数显示，新论文仍推荐字符串。若其他表采用不同精度，保留字符串并按真实数据适配。

**自动检查的边界：** 它不能判断英文是不是原文、是否把整节塞入一个单元、译文是否忠实、表格源 JSON 是否抄错、裁图是否正确，或页面在浏览器里能否实际解码和交互。PASS 只能说明已检查的不变量通过。

## 原文审校与浏览器验收

先按源清单逐项确认覆盖，不以译文字数或 DOM 数量证明全文完整。每个已承诺范围的原文段落都有译文；每条译文有明确原文依据。对数字及限定语，检查源文 → 双语数据 → 页面三者一致。参考文献保留作者及出处，按项目惯例提供题名翻译；不要凭记忆补全引用。

浏览器至少覆盖：

- 中文、英文、对照：每次切换查看正文、图表注及代码块，对照按段落交替，隐藏内容不占位。
- 桌面和窄屏：正文、长图、宽表和提示词块均可读；整页宽度不超过视口；只有宽表／必要公式自身滚动。
- 图片：等待真实 `load`／解码完成，检查 `naturalWidth`，逐一放大；不能只检查 `<img>` 数量。
- 目录与搜索：点击跳转位置未被顶栏遮挡；中文和英文查询按模式返回对应内容；手机目录可打开、关闭及用键盘退出。
- 字号、主题、打印：操作后没有内容丢失、图内颜色被强制反转、图表裁切或打印导航遮挡正文。
- 索引：新旧论文阅读页及 PDF 仍可打开，无重复卡片、旧标题或错误计数。

浏览器截图只用于验收，不作为论文插图交付。无浏览器可用时报告没有完成视觉验收，不能把结构审计称为视觉验证。网络或解析失败时保留已完成工作，明确具体缺口；不要以模型概述、空占位图或整页截图代替。


## 共用阅读器发布格式

本项目发布页为轻量外壳。审计时必须传入 `--document public/content/<paper-id>/paper.<实际摘要>.json`，完整命令与浏览器验收见仓库 README；直接检查外壳不能证明正文完整。独立原图以文件发布，不再要求嵌入 Base64。保留原图字节、来源与 SHA-256，并通过 HTTP 检查实际图片解码、MathML、表格、搜索、打印及仓库子路径。
