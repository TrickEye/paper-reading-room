## 方法

### 问题形式化

**智能体设置：**

agent F 与环境 E 交互，每一步 t 接收观察 o_t，从技能库 S 检索技能，产生动作 a_t

技能库S是唯一可优化变量

**分层技能库**：S分为通用专用技能 $S^G, S^T$ 每个 $S^{T_c}$ 针对 c 类任务的行动指导。推理时用编码器检索通用技能和专属技能

模型卡：模型基本信息

目标：定义调整后奖励，奖励任务成功，惩罚技能停滞导致环境不变

### 分层技能优化

1. 迭代爬山搜索优化通用技能

   1. 执行：目标模型F运行所有技能类型，计算奖励
   2. 分析：收集失败轨迹，归因，关注通用行为缺陷
   3. 改写：输出修订
   4. 接收或拒绝
2. 按任务类型树搜索，优化专用技能

   1. 选择：从根节点，递归用UCB1选择最有希望节点
   2. 扩展：选用节点技能集运行c类任务，收集失败轨迹，归因，输出修订
   3. 评估：评估新子节点技能
   4. 传播：沿路径传回根节点
